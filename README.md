# Voice Loop

A one-page, hands-free voice conversation with Claude for a phone browser. Tap the circle, talk, pause; it sends your turn to the Claude API, reads the reply aloud, and listens again.

- **Open it:** https://johntmorgan.github.io/voice-loop/
- **API key:** paste it into Settings in the app. It is stored only in that browser. Never commit a key to this repo.
- **Hearing and speaking:** the browser's built-in speech recognition and text-to-speech. Chrome on Android is the most reliable; Safari on iPhone works but is flakier.
- **Everything is in `index.html`.** There is no build step and no server.
